# Image Classification Experiments

Academic Python/PyTorch project by Bianca-Anastasia Mircea.

Experiments with neural-network classification of skin-lesion and camera-trap images. Includes data exploration, preprocessing and augmentation, model training, validation metrics and confusion-matrix visualization.

## Files and environment

- `Tema2-IA-Mircea-Bianca-Anastasia-cod.ipynb`: original notebook with saved outputs and execution counters cleared.
- `Tema2-IA-Mircea-Bianca-Anastasia-raport.pdf`: original report.
- `requirements.txt`: packages imported by the notebook, without unverified version pins.

The external datasets are not included. The notebook references `vai-de-pielea-mea.zip` and `you-re-on-candid-camera.zip` and contains Kaggle/local path handling; supply the original assignment datasets and check the paths before execution. GPU training benefits from a CUDA-compatible PyTorch installation. Models were not trained or evaluated again during portfolio preparation. This is an academic classification experiment, not a clinical diagnostic tool.
